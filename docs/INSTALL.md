## 1. ความต้องการของระบบ

| รายการ | ขั้นต่ำ | หมายเหตุ |
|---|---|---|
| PHP | 8.0 ขึ้นไป | ทดสอบแล้วกับ PHP 8.0 (XAMPP 8.0.30) |
| ส่วนขยาย PHP | `mysqli` (mysqlnd), `mbstring`, `fileinfo`, `json` | XAMPP เปิดไว้ครบแล้ว |
| ฐานข้อมูล | MySQL 5.7+ หรือ MariaDB 10.3+ | charset `utf8mb4` |

## 2. ติดตั้งบนเครื่องด้วย XAMPP (Windows)

### 2.1 ติดตั้ง XAMPP
1. ดาวน์โหลด XAMPP (PHP 8.x) จาก <https://www.apachefriends.org> แล้วติดตั้งที่ `C:\xampp`
2. เปิด **XAMPP Control Panel** → กด **Start** ที่ **Apache** และ **MySQL** (ขึ้นสีเขียว)

### 2.2 วางไฟล์ระบบ
1. คัดลอกโฟลเดอร์ `teachhub_pt` ไปไว้ที่ `C:\xampp\htdocs\teachhub_pt`
2. ตรวจว่ามีไฟล์ที่ขึ้นต้นด้วยจุดครบ (Windows อาจซ่อนไว้): `.htaccess` (ที่ root, `uploads/`, `config/`, `includes/`, `docs/`) และ `.user.ini`

### 2.3 สร้างฐานข้อมูล
1. เปิด <http://localhost/phpmyadmin>
2. เมนู **Databases** → ช่อง Database name พิมพ์ `teachhub_pt` → Collation เลือก **utf8mb4_unicode_ci** → **Create**
3. คลิกฐานข้อมูล `teachhub_pt` ทางซ้าย → แท็บ **Import** → **Choose File** เลือก `C:\xampp\htdocs\teachhub_pt\database.sql` → **Import**
4. (ไม่บังคับ) ถ้าต้องการทดลองใช้งานด้วยข้อมูลตัวอย่าง ให้ Import ไฟล์ `sample_data.sql` ต่อ (ได้บัญชีครู/หัวหน้าแผนก/ผู้บริหาร รหัส `teach1234`)

> ใช้ Command line แทนได้:
> ```bash
> cd C:\xampp\mysql\bin
> mysql -u root -e "CREATE DATABASE teachhub_pt CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"
> mysql -u root --default-character-set=utf8mb4 teachhub_pt < C:\xampp\htdocs\teachhub_pt\database.sql
> ```

### 2.4 ตั้งค่าการเชื่อมต่อฐานข้อมูล
เปิดไฟล์ `config/db.php` (ค่าเริ่มต้นของ XAMPP ใช้ได้ทันที):
```php
define('DB_HOST', 'localhost');
define('DB_PORT', 3306);
define('DB_USER', 'root');
define('DB_PASS', '');            // XAMPP ค่าเริ่มต้นไม่มีรหัสผ่าน
define('DB_NAME', 'teachhub_pt');
```

### 2.5 ปรับขนาดไฟล์อัปโหลด (ถ้าต้องการเกิน 40MB)
แก้ `C:\xampp\php\php.ini` แล้ว Restart Apache:
```ini
upload_max_filesize = 40M
post_max_size = 50M
date.timezone = Asia/Bangkok
```

### 2.6 เข้าใช้งาน
1. เปิด <http://localhost/teachhub_pt>
2. กด **เข้าสู่ระบบ** → ชื่อผู้ใช้ `admin` รหัสผ่าน `admin1234`
3. ระบบบังคับให้ **เปลี่ยนรหัสผ่าน** ทันที (อย่างน้อย 8 ตัว มีตัวอักษรและตัวเลข)
4. เข้าเมนู **ระบบ → ตรวจสอบระบบ** ทุกข้อควรเป็นสีเขียว (บนเครื่อง localhost ข้อ APP_DEBUG จะเป็นสีเหลือง ไม่เป็นไร)

### 2.7 ให้เครื่องอื่นในวิทยาลัยเข้าใช้ (เครือข่ายภายใน)
1. ดู IP เครื่องเซิร์ฟเวอร์ด้วยคำสั่ง `ipconfig` (เช่น `192.168.1.10`)
2. อนุญาต Apache ใน Windows Firewall (ครั้งแรกที่ Start Apache Windows จะถาม ให้กด Allow)
3. เครื่องอื่นเข้า `http://192.168.1.10/teachhub_pt`

## 3. ติดตั้งบนโฮสติ้ง (cPanel / DirectAdmin / Plesk)

### 3.1 สร้างฐานข้อมูลและผู้ใช้ฐานข้อมูล
**cPanel** → **MySQL® Database Wizard**
1. สร้างฐานข้อมูล เช่น `teachhub` (ชื่อจริงจะมี prefix เช่น `ptc_teachhub`)
2. สร้างผู้ใช้ เช่น `teachhub` (จะเป็น `ptc_teachhub`) ตั้งรหัสผ่านที่คาดเดายาก
3. ให้สิทธิ์ **ALL PRIVILEGES** แก่ผู้ใช้กับฐานข้อมูลนี้
4. จดชื่อฐานข้อมูล ชื่อผู้ใช้ รหัสผ่าน ไว้

### 3.2 นำเข้าฐานข้อมูล
1. **cPanel → phpMyAdmin** → เลือกฐานข้อมูลที่สร้าง (ด้านซ้าย)
2. ตรวจ Collation: แท็บ **Operations** → Collation = `utf8mb4_unicode_ci` (ถ้าไม่ใช่ให้เปลี่ยน)
3. แท็บ **Import** → เลือก `database.sql` → **Go**
4. **ห้ามนำเข้า `sample_data.sql` บนโฮสติ้งที่ใช้งานจริง**

### 3.3 อัปโหลดไฟล์
1. บีบอัดโฟลเดอร์ `teachhub_pt` เป็น `.zip` บนเครื่อง (ตรวจว่ามีไฟล์ `.htaccess` และ `.user.ini` อยู่ใน zip)
2. **cPanel → File Manager** → เข้า `public_html`
   - ติดตั้งเป็นโฟลเดอร์ย่อย: อัปโหลด zip แล้ว Extract → ได้ `public_html/teachhub_pt` → เข้าใช้ที่ `https://โดเมน/teachhub_pt`
   - ติดตั้งที่ root ของโดเมน/ซับโดเมน: Extract แล้วย้ายไฟล์ทั้งหมดใน `teachhub_pt` ขึ้นไปไว้ที่ root ของโดเมนนั้น
3. ใน File Manager กด **Settings → Show Hidden Files (dotfiles)** เพื่อตรวจว่า `.htaccess` ทุกไฟล์ขึ้นไปครบ
4. ตั้งสิทธิ์: โฟลเดอร์ `755`, ไฟล์ `644` (โฟลเดอร์ `uploads` และโฟลเดอร์ย่อยต้องเขียนได้ = `755` เพียงพอบนโฮสติ้งทั่วไป)

### 3.4 ตั้งค่าระบบ
1. แก้ `config/db.php` ด้วยค่าจากข้อ 3.1:
   ```php
   define('DB_HOST', 'localhost');          // ส่วนใหญ่เป็น localhost (ดูจากหน้าข้อมูลโฮสติ้ง)
   define('DB_USER', 'ptc_teachhub');
   define('DB_PASS', 'รหัสผ่านฐานข้อมูล');
   define('DB_NAME', 'ptc_teachhub');
   ```
2. แก้ `config/config.php` บรรทัดบนสุด ปิดการแสดงข้อผิดพลาด:
   ```php
   define('APP_DEBUG', false);
   ```
3. ถ้า URL ของระบบไม่ถูกต้อง (CSS ไม่โหลด/ลิงก์ผิด) ให้กำหนด BASE_URL เองใน `config/config.php` ก่อนบล็อก `if (!defined('BASE_URL'))`:
   ```php
   define('BASE_URL', '/teachhub_pt');   // ติดตั้งในโฟลเดอร์ย่อย
   // define('BASE_URL', '');            // ติดตั้งที่ root ของโดเมน
   ```

### 3.5 ขนาดไฟล์อัปโหลดบนโฮสติ้ง
- โฮสติ้งที่ใช้ PHP-FPM อ่านค่าจากไฟล์ `.user.ini` ที่แนบมา (32M/40M) — รอประมาณ 5 นาทีหลังอัปโหลด
- cPanel บางแห่งตั้งที่ **Select PHP Version → Options** หรือ **MultiPHP INI Editor** → `upload_max_filesize`, `post_max_size`
- ตรวจผลได้ที่เมนู **ตรวจสอบระบบ** หัวข้อ “ขนาดไฟล์สูงสุด”

### 3.6 เปิด HTTPS
- **cPanel → SSL/TLS Status** หรือ **Let's Encrypt** → ออกใบรับรองให้โดเมน
- เมื่อเข้าผ่าน `https://` ระบบจะตั้ง cookie แบบ Secure ให้อัตโนมัติ

### 3.7 เลือกเวอร์ชัน PHP
**cPanel → Select PHP Version / MultiPHP Manager** → เลือก PHP 8.0 ขึ้นไป และเปิดส่วนขยาย `mysqlnd`, `mysqli`, `mbstring`, `fileinfo`

## 4. ติดตั้งบน VPS ที่ใช้ Nginx

Nginx ไม่อ่านไฟล์ `.htaccess` ต้องเพิ่มกฎป้องกันในไฟล์ตั้งค่าเอง ดูตัวอย่างที่ `docs/nginx.conf.example` (บล็อก `uploads/`, `config/`, `includes/`, `docs/`, ไฟล์ `.sql` และไฟล์ที่ขึ้นต้นด้วยจุด) แล้ว:
```bash
sudo nginx -t
sudo systemctl reload nginx
sudo chown -R www-data:www-data /var/www/teachhub_pt/uploads
```
ตั้ง `upload_max_filesize` / `post_max_size` ใน `php.ini` ของ PHP-FPM และ `client_max_body_size` ใน Nginx ให้สอดคล้องกัน

### อัปเดตจากเวอร์ชัน 1.9 เป็น 1.10 (ผู้ตรวจงานตามตำแหน่ง)
คัดลอกไฟล์ระบบใหม่ทับ **ยกเว้น** `config/db.php` และ `uploads/` — **ไม่มีไฟล์ SQL** ต้องนำเข้า
จากนั้น admin เข้า จัดการผู้ใช้ → แก้ไขผู้ใช้ แล้วตั้ง **ตำแหน่ง** ให้ผู้ตรวจแต่ละงาน (ตำแหน่งต้องสะกดตรงตามนี้ เลือกจากรายการได้):

| ตำแหน่ง | ตรวจงาน |
|---|---|
| หัวหน้างานส่งเสริมการวิจัย นวัตกรรม และสิ่งประดิษฐ์ | เค้าโครงวิจัย / งานวิจัยในชั้นเรียน |
| หัวหน้างานบุคลากร | ข้อตกลงในการพัฒนางาน (PA) |
| หัวหน้างานพัฒนาหลักสูตรและการจัดการเรียนรู้ · เจ้าหน้าที่งานพัฒนาหลักสูตรและการจัดการเรียนรู้ | โครงการสอน / แผนการจัดการเรียนรู้ |

- ผู้ตรวจตามตำแหน่งตรวจได้ทุกแผนก ยกเว้นงานของตนเอง · หัวหน้าแผนกยังตรวจงานของครูในแผนกได้เหมือนเดิม · ผู้ดูแลระบบตรวจ/แก้ผลได้ทุกงาน
- ผู้ใช้ตั้งหรือเปลี่ยนตำแหน่งผู้ตรวจเองไม่ได้ (ทั้งตอนสมัครและในโปรไฟล์) ต้องให้ผู้ดูแลระบบกำหนด

### อัปเดตจากเวอร์ชัน 1.8 เป็น 1.9 (สำรอง/กู้คืนข้อมูล)
คัดลอกไฟล์ระบบใหม่ทับ **ยกเว้น** `config/db.php` และ `uploads/` — **ไม่มีไฟล์ SQL** ต้องนำเข้า
ต้องเปิดส่วนขยาย PHP `zip` (XAMPP เปิดไว้แล้ว) จากนั้นเข้าเมนู สำรอง / กู้คืนข้อมูล แล้วสร้างไฟล์สำรองแรกได้ทันที (ดูหัวข้อ 7.1)

### อัปเดตจากเวอร์ชัน 1.7 เป็น 1.8 (ส่งโครงการสอน/แผนการจัดการเรียนรู้ที่จุดเดียว)
1. สำรองฐานข้อมูลก่อน แล้วคัดลอกไฟล์ระบบใหม่ทับ **ยกเว้น** `config/db.php` และ `uploads/`
2. phpMyAdmin → Import → `update_v1.8.sql` (ถ้ายังเป็น 1.6 ให้นำเข้า `update_v1.7.sql` ก่อน)
3. รอบการส่งประเภท “แผนการจัดการเรียนรู้” รอบเดียวรับได้ทั้งโครงการสอนและแผนการจัดการเรียนรู้ — ครูเลือก **ประเภทเอกสาร** จาก list ในฟอร์มส่ง
   (รอบ “โครงการสอนรายวิชา” แบบเดิมถูกเปลี่ยนเป็นรอบปกติให้อัตโนมัติ งานที่ส่งไว้แล้วไม่เปลี่ยน)

### อัปเดตจากเวอร์ชัน 1.6 เป็น 1.7 (สมัคร/เข้าสู่ระบบด้วยบัญชี Google)

## 6. ขั้นตอนเริ่มใช้งานสำหรับ admin

1. **ตั้งค่าระบบ** (เมนู ระบบ → ตั้งค่าระบบ): ชื่อวิทยาลัย, อัปโหลดโลโก้, ขนาดไฟล์สูงสุด, นามสกุลไฟล์, สีธีม
2. **ปีการศึกษา/ภาคเรียน**: เพิ่มภาคเรียน และตั้ง “ภาคเรียนปัจจุบัน”
3. **แผนกวิชา** และ **รายวิชา**: ตรวจ/เพิ่มให้ครบ
4. **ผู้ใช้**: แจ้งครูสมัครสมาชิกที่ `https://โดเมน/teachhub_pt/auth/register.php` → อนุมัติที่เมนู จัดการผู้ใช้
   - กำหนดหัวหน้าแผนก: แก้ไขผู้ใช้ → Role = หัวหน้าแผนก/ผู้นิเทศ (1 แผนกควรมีอย่างน้อย 1 คน)
   - เพิ่มผู้บริหาร: เพิ่มผู้ใช้ → Role = ผู้บริหาร
5. **หัวข้อแบบประเมินนิเทศ**: ตรวจ/แก้ไขให้ตรงกับแบบนิเทศของวิทยาลัย
6. **เอกสารดาวน์โหลด**: อัปโหลดแบบฟอร์มแผนการสอน แบบ PA เค้าโครงวิจัย แบบนิเทศ
7. **รอบการส่งงาน**: สร้างรอบของแต่ละงาน กำหนดวันเวลาเปิด-ปิด และอนุญาตส่งช้าหรือไม่
8. **ประกาศข่าว**: ประกาศกำหนดการให้ครูทราบ
9. **นิเทศโดยหัวหน้าแผนก**: สร้างตารางนิเทศ (admin หรือหัวหน้าแผนก)
10. **นิเทศโดยนักเรียน**: เมนู นิเทศการสอน → 2. โดยนักเรียน (QR Code) → สร้างแบบประเมิน (เลือกครู วิชา ห้อง ช่วงเวลา จำนวนผู้ตอบสูงสุด)
    → กด “พิมพ์ป้าย QR” หรือให้ครูเปิด QR จากเมนู ผลการนิเทศของฉัน → แท็บ 2 แล้วฉายให้นักเรียนสแกนในห้อง
11. **รายงานการนิเทศ**: หัวหน้าแผนกเข้าเมนู “รายงานการนิเทศ (เสนอผู้บริหาร)” → จัดทำรายงาน → เขียนสรุป/ข้อเสนอแนะ → เสนอ
    ผู้พิจารณาแต่ละขั้นจะเห็นแจ้งเตือนบนแดชบอร์ด และพิจารณาได้ที่เมนู “รายงานการนิเทศ (พิจารณา)” → พิมพ์บันทึกข้อความเป็น PDF

## 7. การสำรองข้อมูลและย้ายเครื่อง

### 7.1 สำรอง/กู้คืนจากหน้าเว็บ (แนะนำ — เวอร์ชัน 1.9 ขึ้นไป)
เมนู ระบบ → **สำรอง / กู้คืนข้อมูล** (เฉพาะผู้ดูแลระบบ)
- **สำรองข้อมูล**: ได้ไฟล์ `.zip` 1 ไฟล์ (ฐานข้อมูลทุกตาราง + เลือกรวมไฟล์แนบใน `uploads/` ได้) เก็บที่ `uploads/backups/` และกดดาวน์โหลดเก็บไว้นอกเครื่องได้
- **สำรองอัตโนมัติ**: เปิดสวิตช์ แล้วระบบจะสำรองวันละครั้งเมื่อผู้ดูแลระบบเปิดหน้าแดชบอร์ด เก็บไว้ตามจำนวนไฟล์ล่าสุดที่กำหนด
- **กู้คืน**: เลือกไฟล์สำรองบนเซิร์ฟเวอร์ หรืออัปโหลดไฟล์ `.zip` → พิมพ์คำว่า “กู้คืน” + รหัสผ่าน
  - ระบบสำรองข้อมูลปัจจุบันเป็นไฟล์ “ก่อนกู้คืน” ให้อัตโนมัติก่อนทุกครั้ง (ย้อนกลับได้)
  - หลังกู้คืน ทุกคนต้องเข้าสู่ระบบใหม่
  - ไฟล์สำรองที่ใหญ่เกินขนาดอัปโหลด (`upload_max_filesize`) ให้คัดลอกไปไว้ที่ `uploads/backups/` แล้วเลือกจากรายการ
    (ชื่อไฟล์ต้องคงรูปแบบเดิม เช่น `teachhub_20261017_103000_a1b2c3.zip`)
- **ย้ายเครื่อง**: ติดตั้งระบบใหม่ด้วย `database.sql` → เข้าด้วย admin → อัปโหลดไฟล์สำรองเพื่อกู้คืน
- ควรใช้ไฟล์สำรองจากระบบเวอร์ชันเดียวกัน (รายการไฟล์สำรองแสดงป้าย “ต่างจากปัจจุบัน” ถ้าเวอร์ชันไม่ตรง)

### 7.2 สำรองด้วยตนเอง (phpMyAdmin)
ข้อมูลของระบบมี 2 ส่วน ต้องสำรอง **ทั้งคู่**
1. **ฐานข้อมูล**: phpMyAdmin → เลือกฐานข้อมูล → Export → Quick → SQL
   หรือ `mysqldump -u root -p --default-character-set=utf8mb4 teachhub_pt > backup_YYYYMMDD.sql`
2. **ไฟล์ที่อัปโหลด**: โฟลเดอร์ `uploads/` ทั้งหมด (บีบอัดเป็น zip)

แนะนำสำรองอย่างน้อยสัปดาห์ละ 1 ครั้ง และทุกครั้งก่อนปิดรอบการส่งงานสำคัญ

**ย้ายเครื่อง**: คัดลอกโฟลเดอร์ระบบ + `uploads/` → สร้างฐานข้อมูลใหม่ → Import ไฟล์ backup (ไม่ต้อง import `database.sql` ซ้ำ) → แก้ `config/db.php`

## 8. แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| “ไม่สามารถเชื่อมต่อฐานข้อมูลได้” | ตรวจค่าใน `config/db.php`, MySQL ทำงานอยู่หรือไม่ (XAMPP: Start MySQL) |
| ภาษาไทยเป็น `????` | ฐานข้อมูล/ตารางไม่ใช่ utf8mb4 → สร้างฐานข้อมูลใหม่ด้วย `utf8mb4_unicode_ci` แล้ว import ใหม่ |
| หน้าเว็บไม่มีสี/CSS ไม่โหลด | BASE_URL ไม่ตรง → กำหนดเองตามข้อ 3.4 ข้อ 3 / หรือเครื่องผู้ใช้ไม่มีอินเทอร์เน็ต (CDN) |
| 500 Internal Server Error ทันทีหลังอัปโหลดขึ้นโฮสติ้ง | โฮสติ้งไม่อนุญาตคำสั่งบางตัวใน `.htaccess` (เช่น `Options`) → ลบบรรทัด `Options -Indexes` ใน `.htaccess` ที่ root และ `uploads/.htaccess` ทีละบรรทัดเพื่อหาบรรทัดที่เป็นปัญหา |
| “ไฟล์มีขนาดใหญ่เกินกว่าที่เซิร์ฟเวอร์รับได้” | เพิ่ม `upload_max_filesize`/`post_max_size` (ข้อ 2.5 / 3.5) |
| “แบบฟอร์มหมดอายุหรือไม่ถูกต้อง” (419) | เปิดหน้าทิ้งไว้นานจน session หมดอายุ → รีเฟรชหน้าแล้วทำใหม่ / ปรับเวลาหมดอายุที่ ตั้งค่าระบบ |
| อัปโหลดแล้วขึ้น “ชนิดไฟล์ไม่ตรงกับนามสกุล” | ไฟล์ถูกเปลี่ยนนามสกุลเอง หรือไฟล์เสีย → ให้บันทึก/Export จากโปรแกรมต้นทางเป็น PDF/DOCX ใหม่ |
