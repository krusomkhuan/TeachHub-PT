# TeachHub PT

**ระบบการส่งงานและรายงานกิจกรรม — วิทยาลัยการอาชีพโพนทอง**
> “ทุกงานวิชาการครบ จบในที่เดียว”

ผู้พัฒนาระบบ: ครูสมควร สากำ · เวอร์ชัน 1.17.0

---

## ความสามารถของระบบ

| โมดูล | รายละเอียด |
|---|---|
| ระบบสมาชิก | สมัครสมาชิก → รอ admin อนุมัติ, เข้าสู่ระบบ, **สมัคร/เข้าสู่ระบบด้วยบัญชี Google** (เปิดที่ตั้งค่าระบบ จำกัดโดเมนอีเมลได้ เชื่อม/ยกเลิกเชื่อมที่โปรไฟล์), ลืมรหัสผ่าน (admin รีเซ็ต), โปรไฟล์ + รูปโปรไฟล์, เปลี่ยนรหัสผ่าน, หมดเวลา session อัตโนมัติ |
| หน้าบ้าน | หน้าแรก + สถิติ, ประกาศข่าวสาร, ปฏิทินกำหนดส่งงาน + นับถอยหลัง, ดาวน์โหลดแบบฟอร์ม (แยกหมวดหมู่ที่ admin เพิ่ม/แก้ไขเองได้) |
| รอบการส่งงาน | admin กำหนดวันเวลาเปิด-ปิดของทุกงาน, ตรวจเวลาฝั่งเซิร์ฟเวอร์, อนุญาตส่งช้า (ติดป้าย “ส่งช้า”) |
| 1. โครงการสอน / แผนการจัดการเรียนรู้ | ครูบันทึก **รายวิชาที่สอน** ของแต่ละภาคเรียนก่อน แล้วส่งโครงการสอนและแผนการจัดการเรียนรู้ (PDF/DOCX) **ที่จุดเดียวกัน** โดยเลือกประเภทเอกสารจาก list และเลือกวิชาจากรายวิชาที่สอน, ตรวจ ผ่าน/ให้แก้ไข + ความเห็น, ส่งใหม่ได้ เก็บทุกเวอร์ชัน · **เกณฑ์รายภาคเรียน:** โครงการสอนครบทุกรายวิชา + แผนการจัดการเรียนรู้อย่างน้อย 1 วิชา (รายงาน “เกณฑ์การส่งรายภาคเรียน”) |
| ประเมินแผนการจัดการเรียนรู้ | แบบประเมิน 3 ตอนตามแบบฟอร์มวิทยาลัย (ตรวจองค์ประกอบ 18 รายการ, คุณภาพ 30 ข้อ 6 ด้าน, ข้อเสนอแนะและผลการพิจารณา) ประเมินแผนที่ครูส่งในระบบ แผนละ 1 ผล · **หัวหน้างานพัฒนาหลักสูตรฯ** (ตามตำแหน่ง) และ admin ประเมินได้ทุกแผนก, **หัวหน้าแผนก** เฉพาะแผนกตนเอง · ครูดูผลและกดรับทราบ, พิมพ์แบบประเมิน/PDF ตามฟอร์ม · รายงาน 2 ระดับ: ระดับแผนกวิชา และภาพรวมวิทยาลัย · admin แก้ไขรายการประเมินได้ |
| 2. ข้อตกลงในการพัฒนางาน (PA) | ข้อตกลงต้นปี / รายงานผลปลายปี, ส่วนที่ 1–2, แนบไฟล์ |
| 3. วิจัยในชั้นเรียน | เค้าโครง → (ผ่าน) → รายงานฉบับสมบูรณ์ |
| 4.1 นิเทศโดยหัวหน้าแผนก | ตารางนิเทศ (รายวิชาเลือกได้เฉพาะวิชาที่แผนการจัดการเรียนรู้ “ผ่าน” แล้ว — ใช้กับการประเมินโดยนักเรียนด้วย), แบบประเมินออนไลน์ 5 ระดับ 15 รายการ 6 ด้าน (หัวข้อแก้ได้), คะแนนเฉลี่ย/ระดับคุณภาพอัตโนมัติ, แนบภาพถ่ายได้ถึง 10 รูป (ถ่ายจากกล้องโทรศัพท์ได้ทันที ระบบย่อขนาดให้อัตโนมัติ), ครูกดรับทราบ, พิมพ์ PDF |
| 4.3 รายงานการนิเทศ | หัวหน้าแผนกจัดทำรายงาน (ระบบดึงผลการนิเทศ คะแนนรายครู/รายด้าน คะแนนจากนักเรียน และภาพถ่ายให้อัตโนมัติ) → เสนอ **หัวหน้างานพัฒนาหลักสูตรและการจัดการเรียนรู้ → รองผู้อำนวยการฝ่ายวิชาการ → ผู้อำนวยการ** แต่ละขั้นให้ความเห็น/ส่งกลับแก้ไขได้ → พิมพ์เป็น “บันทึกข้อความ” พร้อมความเห็นทุกขั้นและภาคผนวกภาพ |
| 4.2 นิเทศโดยนักเรียน นักศึกษา | admin สร้างแบบประเมิน (ครู + วิชา + กลุ่มนักเรียน **ปวช. ปี 1–3 / ปวส. ปี 1–2** + ช่วงเวลา) → ได้ลิงก์/QR Code, นักเรียนสแกนประเมินได้**โดยไม่ต้องเป็นสมาชิก** ไม่ระบุตัวตน 1 เครื่อง/1 ครั้ง, หัวข้อแยกชุด, ครูเห็นเฉพาะ QR และผลของตนเอง, หัวหน้าแผนกเห็นผลของแผนก |
| 5. รายงานครูที่ปรึกษา | ครูที่ปรึกษาส่งรายงานการพบนักเรียน **สัปดาห์ละ 1 ครั้ง ทุกวันพุธ** (1 รายงาน/กลุ่มเรียน): จำนวนนักเรียน มา/มาสาย/ลา/ขาด, เรื่องที่พูดคุย, นักเรียนที่มีปัญหาและการช่วยเหลือ, ภาพถ่าย 1–3 ภาพ · ส่งย้อนหลังได้ เลยกำหนด (ค่าเริ่มต้นภายใน 2 วันหลังวันพุธ) ติดป้าย “ส่งช้า” · งานครูที่ปรึกษาและแนะแนวกำหนดครูที่ปรึกษา/กลุ่มเรียนรายภาคเรียนและวันพุธที่งดพบ ตรวจ ผ่าน/ให้แก้ไข · สรุปรายครู (ส่งกี่สัปดาห์/ขาดส่งสัปดาห์ใด) และภาพรวมทั้งวิทยาลัย/รายแผนก ส่งออก Excel |
| 6. รายงานการเยี่ยมบ้าน | ครูที่ปรึกษาบันทึกการเยี่ยมบ้านนักเรียนในที่ปรึกษา **นักเรียน 1 คน 1 ครั้งต่อปีการศึกษา** (ไม่กำหนดเป้า): รหัส/ชื่อนักเรียน กลุ่ม วันที่ ผู้ให้ข้อมูล ที่อยู่ พิกัด GPS (ไม่บังคับ) อาศัยอยู่กับ ฐานะ สภาพครอบครัว ด้านการเรียน/พฤติกรรม ผลคัดกรอง (ปกติ/เสี่ยง/มีปัญหา) การช่วยเหลือ ภาพ 1–3 ภาพ · งานครูที่ปรึกษาและแนะแนวตรวจ ผ่าน/ให้แก้ไข · สรุปรายครูและภาพรวม/รายแผนก กราฟรายเดือน ส่งออก Excel |
| รายงาน | แยก 5 งาน (แผน/PA/วิจัย/นิเทศโดยหัวหน้าแผนก/นิเทศโดยนักเรียน), กรองปี/ภาคเรียน/รอบ/แผนก/สถานะ (นิเทศโดยนักเรียนกรองระดับ ปวช./ปวส. และสรุปตามระดับ-ชั้นปีได้), ร้อยละ, กราฟรายแผนก, ส่งออก Excel (CSV), พิมพ์/PDF |
| ข้อตกลง PDPA | หน้าข้อตกลงการคุ้มครองข้อมูลส่วนบุคคล (เมนูหน้าบ้าน/เมนูด้านข้าง/ท้ายหน้า), ยอมรับตอนสมัครสมาชิก, ผู้ใช้ที่ยังไม่ยอมรับฉบับปัจจุบันต้องยอมรับก่อนใช้งาน, admin แก้เนื้อหา ประกาศฉบับใหม่ เปิด/ปิดการบังคับ และดูสถานะการยอมรับรายบุคคล |
| ผู้ดูแลระบบ | ผู้ใช้, แผนก, ภาคเรียน, รายวิชา, รอบการส่ง, ประกาศ, เอกสาร, หัวข้อประเมิน, ตั้งค่าระบบ, Log, ตรวจสอบระบบ |
| กระดานข่าว | ช่องทางติดต่อประสานงาน **เฉพาะสมาชิก**: ตั้งกระทู้ 4 หมวด (ประสานงานทั่วไป / สอบถามการใช้งาน / เสนอพัฒนาระบบ / แจ้งปัญหา) ตอบ แก้ไข/ลบข้อความของตนเอง ค้นหา กรองสถานะ · ผู้ดูแลระบบปักหมุด เปลี่ยนสถานะ (รอตอบ → ตอบแล้ว → รับไว้พัฒนา → ดำเนินการแล้ว / ปิดกระทู้) และลบข้อความ |
| สำรอง / กู้คืนข้อมูล | admin สร้างไฟล์สำรอง .zip (ฐานข้อมูล + ไฟล์แนบ) ดาวน์โหลดได้, สำรองอัตโนมัติวันละครั้ง (กำหนดจำนวนไฟล์ที่เก็บ), กู้คืนจากไฟล์บนเซิร์ฟเวอร์หรืออัปโหลด (ยืนยันด้วยรหัสผ่าน + สำรองข้อมูลก่อนกู้คืนให้อัตโนมัติ) |

## ระดับผู้ใช้

| Role | สิทธิ์ |
|---|---|
| `admin` เจ้าหน้าที่งานพัฒนาหลักสูตรและการจัดการเรียนรู้ | จัดการทุกอย่าง ตรวจงานได้ทุกแผนก |
| `admin` แบบ **เจ้าหน้าที่ดูแลระบบ (กำหนดสิทธิ์)** | ผู้ดูแลระบบเต็มสิทธิ์ติ๊กเลือกเมนูที่ใช้ได้ทีละรายการ (มีแม่แบบสิทธิ์) ที่หน้าแก้ไขผู้ใช้ — เห็นเฉพาะเมนูที่ได้รับสิทธิ์ และทุกหน้าตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ (เปิด URL ตรงจะถูกปฏิเสธ) · แก้ไขบัญชีผู้ดูแลระบบ/สิทธิ์ของตนเองไม่ได้ · ต้องมีผู้ดูแลระบบเต็มสิทธิ์อย่างน้อย 1 คนเสมอ |
| ผู้ตรวจงานตามตำแหน่ง (กำหนดที่ช่องตำแหน่ง โดย admin) | **หัวหน้างานส่งเสริมการวิจัย นวัตกรรม และสิ่งประดิษฐ์** → ตรวจเค้าโครง/งานวิจัย · **หัวหน้างานบุคลากร** → ตรวจ PA · **หัวหน้างาน/เจ้าหน้าที่งานพัฒนาหลักสูตรและการจัดการเรียนรู้** → ตรวจโครงการสอน/แผน — ตรวจได้ทุกแผนก (ยกเว้นงานของตนเอง) ครูที่อยู่ในตำแหน่งนี้จะมีเมนู “ตรวจงาน (ตามตำแหน่ง)” · **หัวหน้างาน/เจ้าหน้าที่งานครูที่ปรึกษาและแนะแนว** → ตรวจรายงานครูที่ปรึกษาและรายงานการเยี่ยมบ้าน กำหนดกลุ่มที่ปรึกษาและวันงดพบ (เมนู “งานครูที่ปรึกษา (ตามตำแหน่ง)”) |
| `supervisor` หัวหน้าแผนก/ผู้นิเทศ | ตรวจงานและนิเทศครูในแผนกตนเอง, ดูรายงานแผนก, ส่งงานของตนเอง |
| `teacher` ครูผู้สอน | ส่งงาน ดูสถานะ ดูผลนิเทศของตนเองเท่านั้น |
| `executive` ผู้บริหาร (ผู้อำนวยการ, รองผู้อำนวยการฝ่ายบริหารทรัพยากร / ฝ่ายยุทธศาสตร์และแผนงาน / ฝ่ายกิจการนักเรียน นักศึกษา / ฝ่ายวิชาการ) | ดูแดชบอร์ดและรายงานอย่างเดียว — สมัครด้วยตำแหน่งรองผู้อำนวยการไม่ต้องเลือกแผนก และได้สิทธิ์นี้อัตโนมัติเมื่อ admin อนุมัติ |

## เทคโนโลยี

PHP 8.x (ไม่ใช้ Framework) · MySQL/MariaDB ผ่าน MySQLi + Prepared Statements ทุกคำสั่ง · Bootstrap 5 · Bootstrap Icons · ฟอนต์ Sarabun · SweetAlert2 · DataTables · Chart.js

## เริ่มต้นใช้งานอย่างย่อ

1. คัดลอกโฟลเดอร์ไปไว้ที่ `C:\xampp\htdocs\teachhub_pt`
2. สร้างฐานข้อมูล `teachhub_pt` (utf8mb4_unicode_ci) แล้วนำเข้า `database.sql`
3. แก้ `config/db.php` ให้ตรงกับฐานข้อมูล
4. เปิด `http://localhost/teachhub_pt` → เข้าสู่ระบบ **admin / admin1234** → ระบบบังคับเปลี่ยนรหัสผ่าน
5. เข้าเมนู **ตรวจสอบระบบ** เพื่อตรวจความพร้อม

## ความปลอดภัยที่มีในระบบ

- Prepared Statements ทุกคำสั่ง SQL, `htmlspecialchars()` ทุกจุดที่แสดงผล, CSRF Token ทุกฟอร์ม
- `password_hash()` / `password_verify()`, `session_regenerate_id()` หลังล็อกอิน, cookie HttpOnly + SameSite, หมดเวลาอัตโนมัติ
- จำกัดการล็อกอินผิด 5 ครั้ง / 15 นาที ต่อ IP, บังคับเปลี่ยนรหัสผ่านเริ่มต้น
- ตรวจสิทธิ์ทุกหน้าตาม role และตรวจความเป็นเจ้าของงานทุกครั้ง (ครูเห็นเฉพาะงานตนเอง, หัวหน้าแผนกเห็นเฉพาะแผนกตนเอง)
- อัปโหลด: ตรวจนามสกุล + MIME + ลายเซ็นไฟล์, ตั้งชื่อสุ่ม, `uploads/` ห้ามเข้าถึงตรงและห้ามรันสคริปต์, ดาวน์โหลดผ่านสคริปต์ที่ตรวจสิทธิ์
- บันทึกการใช้งาน (Log) ทุกการกระทำสำคัญ พร้อม IP
